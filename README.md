# Список и детали услуг

![CI](https://github.com/EwgeniyNikol/services_list/actions/workflows/ci.yml/badge.svg)

Учебный проект на React с Redux-Saga. Список услуг и страница деталей.

## Возможности
- Список услуг с загрузкой и обработкой ошибок
- Детали услуги по ID
- Повтор запроса при ошибке
- Спиннер загрузки

## Стек
- React
- Redux
- Redux-Saga
- React Router
- TypeScript
- Vite
- Express (бэкенд)

## Установка и запуск локально
```bash
# Бэкенд
cd backend
npm install
npm start

# Фронтенд
